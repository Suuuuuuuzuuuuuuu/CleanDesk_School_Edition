# 📂 Шкільний органайзер файлів (CleanDesk v1.0 (School Edition))

Зручний, простий і безпечний Python-скрипт для вчителів, який автоматично наводить лад на робочому столі або у вибраній папці з навчальними матеріалами.

## ✨ Можливості
- **Розумне розпізнавання:** автоматично сортує календарні плани, конспекти, презентації, журнали оцінок, КТП, матеріали НУШ та контрольні роботи за назвами й типами файлів.
- **Окрема папка «Школа»:** збирає робочі матеріали в окрему директорію, не змішуючи їх із особистими фото та завантаженнями.
- **Захист класів:** папки конкретних класів (наприклад, `5-А`, `7-B`, `9-А клас`) та їхній внутрішній вміст залишаються повністю неторканими.
- **Тестовий режим (Dry Run):** дозволяє спочатку безпечно переглянути звіт без реального переміщення файлів.
- **Захист від дублікатів:** файли з однаковими назвами не перезаписуються, а автоматично нумеруються (`документ_1.docx`).
- **Дружній інтерфейс:** мінімум ручного вводу — на більшість запитань можна відповісти простим натисканням клавіші `Enter`.

## 🚀 Встановлення та запуск
1. Встановіть [Python](https://www.python.org/) (версія 3.7 або новіша).
2. Завантажте файли `main.py` та `config.py` в одну папку.
3. Запустіть файл `main.py` подвійним кліком миші або через термінал:
   ```bash
   python main.py
